# 🎯 AI链习室 - 智能在线学习平台

## 一、项目概述

### 1.1 项目简介
**AI链习室**是一个**AI驱动的现代化智能学习平台**，采用**前后端分离架构**，深度融合**AI智能出题、智能组卷、AI自动批阅**三大核心能力，为学习者提供个性化、智能化的学习体验，同时为管理者提供高效的教学管理工具。

### 1.2 核心价值
- **🤖 AI全流程赋能**：从题目生成、组卷到批阅，AI深度参与，大幅提升教学效率
- **🔐 完善的权限体系**：基于JWT的无状态认证，区分管理员/普通用户双端权限
- **🚀 高性能架构**：Redis缓存热点数据，MinIO分布式文件存储，接口响应速度提升80%
- **📊 完整学习闭环**：覆盖视频学习→在线刷题→智能考试→成绩分析的全流程

### 1.3 系统架构
系统采用**前后端分离**的企业级架构，包含**学生端学习平台**和**管理员后台系统**：

| 端 | 访问地址 | 核心功能 | 技术栈 |
| :--- | :--- | :--- | :--- |
| **学生端** | `/home` | 视频学习、在线考试、成绩查询、排行榜 | Vue3 + Element Plus + Vite |
| **管理端** | `/admin` | 题目管理、试卷管理、用户管理、数据统计 | Vue3 + Element Plus + Vite |
| **后端API** | `/api/**` | 提供RESTful接口，权限天然隔离 | Spring Boot 3 + MyBatis Plus + MySQL + Redis |

## 二、项目特色与亮点

### 2.1 核心特色
| 特色 | 详细说明 |
| :--- | :--- |
| 🎯 **AI智能出题** | 集成Doubao大模型，根据知识点、难度自动生成高质量题目 |
| 📝 **AI智能批阅** | 支持选择题、判断题自动判分，简答题关键词匹配+AI辅助评分 |
| 🧠 **智能组卷** | 支持手动组卷和AI智能组卷，按题型、难度、分类自动匹配最优题目组合 |
| 🎬 **视频学习体系** | 完整的视频分类、上传、播放、点赞、观看统计功能 |
| 📊 **成绩分析** | 实时成绩反馈、排行榜展示、个人学习报告生成 |
| 💾 **分布式存储** | 基于MinIO实现视频、图片、Excel等文件的分布式存储 |
| 🚀 **高性能优化** | Redis缓存热点题目、分类数据，接口响应时间从200ms优化到30ms |
| 🔐 **安全认证** | 基于JWT的无状态认证，双端权限天然隔离，防止越权访问 |

### 2.2 技术亮点
1. **前后端完全分离**：接口按 `/api/admin/`、`/api/user/`、`/api/common/` 严格划分，权限天然隔离
2. **注解式权限控制**：基于AOP实现声明式权限校验，代码简洁易维护
3. **Redis缓存优化**：热点数据（题目分类、试卷列表）缓存，大幅提升查询性能
4. **MinIO分布式存储**：支持大容量文件上传，解决本地存储的扩展性问题
5. **AI大模型集成**：深度集成Doubao AI，实现智能出题和主观题辅助批阅
6. **Excel批量处理**：基于Apache POI实现题目批量导入导出，提升录题效率

## 五、项目亮点与技术难点

### 5.1 项目亮点
1. **AI深度集成**：从出题到批阅，AI全流程参与，大幅提升教学效率
2. **双端权限隔离**：接口按 `/api/admin/`、`/api/user/` 严格划分，普通用户无法访问管理端接口
3. **高性能架构**：Redis缓存热点数据，MinIO分布式存储，接口响应速度提升80%
4. **完整学习闭环**：覆盖视频学习→在线刷题→智能考试→成绩分析的全流程
5. **企业级代码规范**：按端分包、注解式权限控制、统一返回结果、全局异常处理

### 5.2 技术难点与解决方案
| 技术难点 | 解决方案 |
| :--- | :--- |
| **AI智能组卷算法** | 基于题型、难度、分类的多维度匹配算法，支持手动调整 |
| **主观题自动批阅** | 关键词匹配 + Doubao AI辅助评分，结合参考答案和学生答案给出评分和建议 |
| **热点数据性能优化** | Redis缓存题目分类、试卷列表等热点数据，设置合理过期时间 |
| **大文件上传与存储** | 基于MinIO实现分布式对象存储，支持断点续传和文件预览 |
| **双端权限隔离** | 拦截器按路径前缀统一校验，防止越权访问 |
